9  Гены вирулентности и устойчивости

Гены ищутся по 55 современным сборкам и 4 древним консенсусам. ABRicate сверяет последовательности с VFDB, RGI — с локальной базой CARD. Этот блок считается в окружении rgi_env.

rgi database --version --local

9.1 Гены вирулентности

При обычных порогах ABRicate VFDB не находит ничего: в virulence_results.tab одна строка заголовка. Порог снижен до 70% идентичности и 70% покрытия.

abricate --db vfdb --minid 70 --mincov 70 \
  ../data/C_H/assemblies_C_H/*fa \
  ../data/C_H/BTC_consensus_C_H/*fa \
  > ../data/C_H/vfdb_results/virulence_results_relaxed.tab
import pandas as pd

df = pd.read_csv('../data/C_H/vfdb_results/virulence_results_relaxed.tab', sep='\t')
df['Sample'] = df['#FILE'].apply(lambda x: x.split('/')[-1].replace('.fa', ''))

matrix = df.pivot_table(
    index='Sample',
    columns='GENE',
    values='%COVERAGE',
    aggfunc='max'
)
matrix = matrix.notna().astype(int)
matrix = matrix[matrix.sum().sort_values(ascending=False).index]
matrix.to_csv('../data/C_H/vfdb_results/virulence_matrix_relaxed.tab', sep='\t')

У четырёх древних консенсусов нет ни одного из этих генов. Находки относятся к адгезии, стрессу и оболочке клетки, не к токсинам. Это согласуется с низкой вирулентностью вида.

9.2 Гены устойчивости

RGI смотрит те же fasta. В матрицу попадают только попадания Perfect и Strict.

mkdir -p ../data/C_H/resistance_results

for file in ../data/C_H/assemblies_C_H/*fa ../data/C_H/BTC_consensus_C_H/*fa; do
    filename=$(basename "$file" .fa)
    rgi main --input_sequence "$file" \
             --output_file "../data/C_H/resistance_results/${filename}" \
             --local --clean --input_type contig
done
import pandas as pd
import glob
import os

rgi_files = glob.glob('../data/C_H/resistance_results/*.txt')

dfs = []
for f in rgi_files:
    sample = os.path.basename(f).replace('.txt', '')
    try:
        df = pd.read_csv(f, sep='\t')
    except pd.errors.EmptyDataError:
        continue
    if df.empty:
        continue
    df['Sample'] = sample
    dfs.append(df)

rgi_all = pd.concat(dfs, ignore_index=True)
rgi_all = rgi_all[rgi_all['Cut_Off'].isin(['Perfect', 'Strict'])]

matrix = rgi_all.pivot_table(
    index='Sample',
    columns='Best_Hit_ARO',
    values='Best_Identities',
    aggfunc='max'
)
matrix = matrix.notna().astype(int)
matrix.to_csv('../data/C_H/resistance_results/resistance_matrix.tab', sep='\t')

print("Матрица:", matrix.shape)

Все четыре древних образца несут только folP. У GCA_963509695.1 сразу четыре класса: аминогликозиды, β-лактам (TEM-1), сульфаниламиды (sul2 и folP) и vanT. У GCA_963554755.1 есть tet(A).

vanT сам по себе не означает устойчивость к ванкомицину: для кластера нужны и остальные гены, в том числе VanG и VanXY.

9.3 Матрица для дерева

Образцы без находок дописываются нулями, чтобы на дереве была вся выборка из 59 листов. Синие метки — гены VFDB, зелёные — CARD. Подписи колонок собираются из самой матрицы, в том же порядке, что и значения.

На коротком дереве древние листья называются иначе, чем fasta. В файле для iTOL стоят те же имена, что в главе про ML-дерево.

FASTA Имя на дереве

import pandas as pd
import glob
import os

all_samples = []
for f in glob.glob('../data/C_H/assemblies_C_H/*fa') + \
         glob.glob('../data/C_H/BTC_consensus_C_H/*fa'):
    all_samples.append(os.path.basename(f).replace('.fa', ''))

all_samples = sorted(set(all_samples))

vf = pd.read_csv('../data/C_H/vfdb_results/virulence_matrix_relaxed.tab', sep='\t', index_col=0)
res = pd.read_csv('../data/C_H/resistance_results/resistance_matrix.tab', sep='\t', index_col=0)

combined = pd.concat([vf, res], axis=1, join='outer')
combined = combined.fillna(0).astype(int)

missing = [s for s in all_samples if s not in combined.index]
if missing:
    missing_df = pd.DataFrame(0, index=missing, columns=combined.columns)
    combined = pd.concat([combined, missing_df])

combined.to_csv('../data/C_H/combined_matrix.tab', sep='\t')
print(f"Образцов: {len(combined)}, генов VFDB: {vf.shape[1]}, генов RGI: {res.shape[1]}")
